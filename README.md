# 息匣 Quieta

给 Android 通知渠道降噪的系统工具。看清谁在乱发通知，批量静音营销渠道，按规则拦截新建渠道。

- 英文名：Quieta
- `applicationId`：`app.quieta`
- 作者：[1290000](https://github.com/1290000)
- 仓库：https://github.com/1290000/Quieta
- 协议：GPL-3.0

## 功能（规划）

1. 渠道盘点  
2. 按 App / 关键词批量静音  
3. 新渠道自动静音（可选）

## 构建

见 [AGENTS.md](AGENTS.md) 中的工程与签名约定。Release 使用统一 `signing.properties`，禁止用 debug 签名冒充正式包。

## 开源

第三方依赖会在应用内「开放源代码许可」页列出，并提供跳转到对应仓库的链接。
